# 펼침형 마인드맵 모드 조사

2026-11-15 조사. 사용자가 데이터 범위를 기존 태그 계층으로 선택했으며, 구현·설정 변경은 없음.

## 공식 자료에서 확인한 동작

- NotebookLM 계열의 Mind Map은 소스의 주제와 관련 개념을 가지 구조로 요약하며, 가지별 펼침·접기, 확대·이동, 노드 선택 후 해당 주제 질문을 지원한다. **요약 생성**과 **마인드맵 탐색 UI**는 구분해야 한다. ([Google 도움말](https://support.google.com/gemininotebook/answer/16212283), [Google 기능 소개](https://blog.google/innovation-and-ai/models-and-research/google-labs/notebooklm-studying-help/))
- Cytoscape.js는 `breadthfirst`의 오른쪽 방향 배치, 직접 좌표를 지정하는 `preset`, 위치·뷰포트 애니메이션을 제공한다. 노드 제거·복원 및 표시 제어도 지원하므로 펼침 상태에 따른 화면 갱신이 가능하다. 숨긴 노드를 단순히 투명하게 만들면 배치 공간은 남으므로, **보이는 노드 집합을 기준으로 재배치**하는 편이 적합하다. ([Cytoscape 공식 문서](https://js.cytoscape.org/#layouts))
- 접근성 기준으로 펼침 상태(`aria-expanded`), 키보드 초점, 방향키 탐색이 필요하다. 캔버스 이벤트만 연결했다고 충족되는 것은 아니며, DOM 기반 탐색 수단을 함께 설계해야 한다. ([WAI-ARIA Tree View](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/))

## 현재 저장소와의 연결

- `src/explorer.ts`: 이미 Cytoscape 사용, 태그 카드·더블클릭 자식 추가·클릭 시 사이드바 연결·확대 및 이동 지원. 현재는 카드들을 수동 탐색하는 화면이며, 가지 접기 후 자동 정렬하는 마인드맵과는 다르다.
- `src/explorer-layout.ts`: 부모·자식·관련 관계 및 태그-노트 연결 계산 재사용 가능.
- `src/hierarchy.ts`, `src/layout.ts`: 전체 사전의 가장 긴 조상 경로에 따른 깊이와 가로 트리 좌표 재사용 가능. 기본 `breadthfirst` 배치를 그대로 쓰면 이 깊이 규칙과 일치하는지 별도 확인이 필요하므로, 기존 좌표를 `preset`에 전달하는 방식을 우선 검토.
- 설치된 `cytoscape` 3.34.4 소스에도 방향 지정 및 `preset` 애니메이션 옵션 존재 확인. 새 라이브러리는 우선 불필요.

## 제안: 기존 태그 기반 마인드맵

데이터 범위는 확인되었으며, 아래 구현 방식은 확정 전 제안이다.

1. 기존 화면을 보존하고 별도 **Mind map** 모드 제공. 태그 하나를 시작점으로 골라 왼쪽→오른쪽으로 작은 라벨과 곡선 연결선 표시.
2. 라벨 선택은 상세 보기, 옆의 펼침 버튼은 자식 한 단계 펼침·접기. 재배치 시 현재 태그와 확대 비율을 최대한 유지. 기존 깊이 팔레트·범례 재사용.
3. 다중 부모가 있으므로 화면은 엄밀한 트리가 아닌 DAG다. 태그를 한 번만 표시하고, 다른 펼친 경로로 도달할 수 있으면 어느 한 부모를 접어도 유지하는 방식을 우선 권장. 주 배치 부모 외의 관계도 삭제하지 않는다.
4. 경로별로 같은 태그를 복제하는 대안은 NotebookLM식 가지 탐색에 가깝지만 화면 노드가 크게 늘 수 있다. 독립 가지 펼침이 핵심인지 확인 후 선택.
5. AI 요약은 이 UI를 만드는 데 필수적이지 않다. 사용자가 실제 요약 생성을 원한다면 소스 선택·모델·저장 위치를 별도 범위로 확정해야 한다.

실제 NotebookLM 계정 화면 조작과 성능·시각 검증은 하지 않았다. 위 구현 방향은 공식 API와 현재 코드에 기반한 판단이다.

## 사용자 확인

사용자는 새 모드의 데이터 범위를 **기존 태그 계층**으로 선택함. 노트 본문의 AI 요약은 이번 범위에서 제외. 사용자는 계획을 승인했고, 별도 뷰 대신 기존 그래프의 네 번째 Mind map 배치로 통합하도록 수정 요청함.

## 구현 반영

기존 그래프의 네 번째 `Mind map` 배치로 구현. 기존 필터·펼침 상태를 공유하고, DOM 버튼과 곡선 연결선으로 표시. 마인드맵 배치는 선택한 루트부터 실제 펼쳐진 부모 연결의 최장 경로를 사용하며, 색상은 전체 사전 depth를 유지. 별도 뷰·AI 요약은 추가하지 않음. 샘플 실화면 조작은 도구 시간 초과로 미완료이며, 렌더러 및 세션 회귀 테스트로 검증.
